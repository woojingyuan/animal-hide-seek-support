隐私政策

游戏进度，留在设备里

本政策说明开发者 Eri Go 提供的「动物躲猫猫」iOS 版本 1.0 如何处理信息，也说明本支持网站与邮件联系的不同情形。

1. 游戏中的信息

游戏不要求注册或登录。应用不收集或向开发者服务器发送个人信息、设备标识符或游戏行为数据；没有广告、内购、聊天、追踪或第三方统计 SDK。

应用在设备内保存已解锁关卡、完成的关卡和印章，以及语音、计时和动画偏好。这些信息用于恢复进度与设置，不由应用上传到开发者服务器。

2. 权限与语音

应用不请求相机、麦克风、位置或通讯录权限。语音引导调用 iOS 的系统语音合成功能朗读游戏提示，不录音、不识别孩子的语音，也不把语音内容发送给开发者。系统语音资源与系统服务由 Apple 提供和管理。

3. 儿童隐私

本游戏面向儿童使用，不索取儿童的姓名、年龄、联系方式或其他个人信息。请家长陪同初次使用，并由成年人发送支持请求；请勿在请求中包含儿童个人资料。

4. 保存与删除

游戏进度和设置保留在本机，直到清除相关数据或删除 App。家长区的「清除游戏进度」会清除关卡与印章，设置偏好仍保留。删除 App 会删除本机应用数据。iOS 设备备份及恢复由你的系统设置管理，恢复备份可能恢复旧数据；应用没有自行实现云端同步。

5. 访问本网站

本网站托管于 GitHub Pages，没有添加分析工具、广告、追踪脚本或表单。提供网页时，GitHub 可能处理 IP 地址和技术日志等访问数据，具体请参阅 GitHub 隐私声明。这与游戏本身不向开发者服务器传送信息的行为不同。

6. 联系支持时提供的信息

如果家长主动通过邮件联系，我们会使用发件邮箱及邮件中自愿提供的信息来处理请求，不用于广告或营销。请仅提供解决问题所需的信息。相关邮件仅在处理支持、后续沟通或履行适用义务所需期间保留；家长可通过同一支持渠道提出查询或删除请求。

如有游戏使用或隐私问题，请由家长联系开发者。

支持与隐私联系邮箱：gokeigen@gmail.com

7. 政策变更

如数据处理方式发生变化，我们会更新此页面及更新日期，并在适用时同步应用中的隐私说明。
